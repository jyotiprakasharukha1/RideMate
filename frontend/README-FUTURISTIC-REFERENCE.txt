# RideMate — Futuristic Premium Automotive UI

This frontend applies the supplied visual reference: a compact midnight-blue automotive interface with cyan and violet neon accents, glass-like panels, premium vehicle cards, dashboard panels and a dark live-tracking surface.

## Install
1. Back up your current `frontend` folder.
2. Extract this ZIP and use the included `frontend` folder.
3. In a terminal opened inside `frontend`, run `npm install` then `npm run dev`.

## Compatibility
The existing `App.jsx`, `LiveFleetMap.jsx`, API requests, authentication, booking and GPS behaviour are preserved. The changes are in styling and page metadata only. No backend or database files are included or modified.

The hero background uses an externally hosted Unsplash image; an internet connection is required for that image to load.
